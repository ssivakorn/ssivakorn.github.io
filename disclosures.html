  • Google Abuse Vulnerability Reward Program — AI-based solving of reCAPTCHA image challenges, 2026
    (Reference: 557908167)
    Free, open-source vision models (CLIP and OWLv2) running locally solved 92.6% of reCAPTCHA sessions at zero cost, without any task-specific training or paid APIs (paper).
  • Discrepancies and RFC violations in the hostname verification of SSL/TLS implementations, 2017
    Several of these flaws could enable man-in-the-middle attacks. Found using HVLearn, an automated black-box testing framework (paper).
    Fixes and advisories:
    • MatrixSSL: github.com/matrixssl/matrixssl/blob/3-9-0-open/CHANGES.md
    • GnuTLS: lists.gnupg.org/pipermail/gnutls-devel/2017-March/008368.html, gitlab.com/gnutls/gnutls/issues/185, gitlab.com/gnutls/gnutls/issues/187
    • Apache HttpClient: issues.apache.org/jira/browse/HTTPCLIENT-1802
    • Java Secure Socket Extension (JSSE): oracle.com/security-alerts/cpujul2017.html
